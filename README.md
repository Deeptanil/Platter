# Platter 🍽️

A modern, fluid food delivery mobile application built with React Native and Expo.

## Features
- **Apple Floating Dock Tab Bar:** Translucent frosted glass tab navigation with dynamic backdrop blur.
- **Mood & Context Discovery:** Filter by dining mood (Street, Party, Healthy, Late Night, Quick Bite) and budget tiers ("Under ₹250").
- **Full Ordering Lifecycle:** Browse restaurants, customize cart, manage delivery addresses, checkout, and live confetti celebration.
- **Cross-Platform:** Native iOS/Android with responsive desktop mobile-frame preview for web.

## Tech Stack
- React Native 0.86 / React 19 / Expo SDK 57
- React Navigation v6 (Native Stack + Bottom Tabs)
- React Native Paper & Reanimated 4
- AsyncStorage offline persistence
